方案总览
  先做 课后卡片，因为它直接复用现有课程 JSON，不依赖新
  课程和图片。然后扩展课程数量，每新增一课都同时生成：
  lesson-XX-data.json、visuals/lessonXX/scene-
  01..06.jpg、web/lesson-XX-data.json、web/visuals/
  lessonXX/...，最后再补音频。

  1. 课后卡片
  目标：每课结束后，把“听完一课”变成“复习一轮”。

  实现方式：

  - 从现有课程数据自动生成卡片，不额外维护一份重复数
    据。

  - 来源字段：
      - key_vocab_summary
      - 每句 lines[].vocab
      - 每句 en / zh
      - speaker / role
      - scene.title_en / scene.title_zh

  - 卡片类型先做 3 种：
      - 词汇卡：英文短语 → 中文含义/例句
      - 句型卡：中文提示 → 英文原句
      - 场景卡：销售/顾客场景 → 适合说哪句话

  - 课后入口：
      - 课程播放结束后显示 开始复习
      - 首页每个课程卡片加 复习卡片

  - 交互：
      - 先显示中文或关键词
      - 点击显示英文答案
      - 用户标记 认识 / 不熟 / 收藏
      - 结果存在 localStorage

  - 停止条件：
      - 本课所有卡片过一遍
      - 显示本课复习结果：掌握数、不熟数、收藏数

  第一版不要做复杂间隔重复算法。先做轻量本地复习，等内
  容多了再做“错题优先”和“隔天复习”。

  2. 扩展课程数量
  建议从现在的 4 课扩到 12 课，先保持每课 6 个场景，每
  场 3-4 句。结构稳定，适合继续自动生成音频和图片。

  建议课程线：

  - Lesson 05：比较不同沙发款式
  - Lesson 06：介绍餐桌、椅子和配套餐厅家具
  - Lesson 07：卧室家具推荐
  - Lesson 08：定制尺寸和颜色
  - Lesson 09：批发客户询价
  - Lesson 10：付款方式和合同条款
  - Lesson 11：包装、物流和交期
  - Lesson 12：售后、投诉和复购

  每课输出格式继续沿用现在的 JSON：

  {
    "lesson_id": "...",
    "title_en": "...",
    "title_zh": "...",
    "description": "...",
    "visual_style": "See style-guide.md for full
    consistency rules",
    "scenes": [],
    "key_vocab_summary": []
  }

  新增课程时要控制难度递进：

  - Lesson 05-06：商品介绍和选择
  - Lesson 07-08：定制、尺寸、颜色、材质
  - Lesson 09-10：商务谈判
  - Lesson 11-12：交付、售后、复购

  3. 图片生成方案：AIClient2API + codex-oauth
  不直接调用外部图片脚本，改成通过本机 AIClient2API 的
  codex-oauth provider 走 OpenAI-compatible API。

  计划使用方式：

  cd /Users/lidechi/Documents/Github/AIClient2API
  npm run help -- --json
  curl http://localhost:3000/provider_health

  确认 codex-oauth provider 可用后，再用类似路由：

  http://localhost:3000/codex-oauth/v1/images/generations

  如果实际帮助信息显示不同路径，就以 A2 的 /api/help
  为准，不硬猜。

  图片生成脚本建议新增：

  scripts/generate_lesson_images_a2.py

  职责：

  - 读取 lesson-XX-data.json
  - 读取 style-guide.md
  - 为每个 scene 组装图片 prompt
  - 调用 AIClient2API codex-oauth
  - 输出到 visuals/lessonXX/scene-01.jpg
  - 同步到 web/visuals/lessonXX/scene-01.jpg
  - 跳过已存在图片，除非传 --force

  命令设计：

  python3 scripts/generate_lesson_images_a2.py
  --lesson-number 05
  python3 scripts/generate_lesson_images_a2.py
  --lesson-number 05 --force
  python3 scripts/generate_lesson_images_a2.py --all-
  missing

  图片 prompt 必须强制复用 style-guide.md 的角色和展厅
  设定，避免人物漂移。每个场景只改变动作、家具、构图细
  节。
